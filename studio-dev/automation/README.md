# 笔记本试跑版自动化

先读包根目录的先看这里.txt，以及本目录的工作台自动化入口与接续.txt。

当前聊天中的 Codex 负责总控；任务中心负责配置店铺、展示状态与保存接续材料。首次只读核对环境，不自动生成图片、采集或发布。

套图使用真实商品参考与原模板：白底1、细节2、种草3、共用尺码1。种草3张的场景、模特和展示方式须有区别。颜色变体保留真实色样与原检查，不将失败图补标通过。

店铺配置使用任务中心的新弹窗，逐行填写紫鸟店铺名、ERP账号和ERP内各站店铺名。名字保存不代表登录或绑定已验证。发布轮转规则见店铺轮转发布规则.txt。

总控技能位于 ../../.agents/skills/amazon-full-pipeline/SKILL.md（相对本文件应从包根目录查找 .agents）。作图技能为 junfei-product-images。所有实际脚本参数以当前 --help 与真实页面状态为准，不能沿用原电脑任务号、SKU或账号号。

现有真实模块保留原身份、预算、任务和回执检查。新作图候选与正式SKU图库交付尚需明确检查及绑定；本版不宣称工作台后台已能无人值守跑完全部轮转。
