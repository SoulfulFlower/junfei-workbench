# 独立账号与套图换色

2026-10-27

## 账号方式

- 首位管理员保留原数据目录，现有产品、图片、文案、API 密钥和版本不移动、不覆盖。变更前已在线备份 SQLite 到 data/account-isolation-backup/20261027-145009。
- 其他账号的数据位于 data/account-workspaces/<用户ID>/，产品库、上传素材、文案、图片任务、助手对话、技能/提示词、DeepSeek/APIMart/卖家精灵密钥独立。
- 为隔离已有模块中的全局模型配置及异步任务，每个活跃员工使用独立后台进程，端口仅监听本机，必须有内部随机令牌且登录账号匹配。公网/局域网仍使用原入口，不能指定他人工作空间。
- 员工进程不继承主机 API 密钥环境变量。密钥仍用 Windows DPAPI 加密，模型 ID 存在各自数据目录，重启保留。
- 统一账号库管理注册/审批/停用。注册 pending 时不能登录；管理员批准后 active；停用撤销会话及插件配对码。
- 每个员工可在模型设置配置和测试自己的 API；管理员账号管理入口不向员工开放。当前隔离优先，未新增跨账号采集缓存复用；不共享私人产品或生成结果。
- 同一浏览器切换账号时，旧页面携带账号标记；服务端拒绝错账号请求，避免将旧页面数据保存到新账号。

## 套图换色

在产品 → ③ 视觉套图 → 套图换色中使用：

1. 文案确认后，完成一套母版图并检查实际质量。
2. 填写目标颜色，选择该颜色的真实供应商/实拍素材，核对是同款同面料。
3. 系统先验证同款，再将母版成图与目标素材同时交给图片模型，保留构图、人物、背景、标识和原图文，只改衣服颜色。
4. 逐张生成与视觉检查，遇到错误停止后续任务；明确失败的图可以单张付费重做，保留历史。
5. 每个颜色单独显示进度、图片和下载；母版不覆盖。AI 编辑无法保证像素完全不变，必须人工核对颜色、面料、结构和商标；AI通过仍为待人工核对。

真实测试：产品 IMP-UK-B0FVS1X3SP，红色供应商参考图，同款验证通过，换色任务 ff29a4d350ed4e9892235a8a9a00fa54。7/7 张生成完成并通过 AI 对照检查，状态仍为待人工确认；结果在该产品内显示。整套缩略图 data/colour-check/red-gallery-contact.jpg，已验证可解压的下载包 data/colour-check/red-gallery.zip。人工查看：整体构图与红色一致，细小商标、文字及面料保真仍需要逐张放大确认。
