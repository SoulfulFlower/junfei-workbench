# 钧飞跨境采集插件 v0.7.15

单机工作台打开后，点顶部「采集插件」生成配对码。在扩展里填写本机工作台地址和配对码，点击「连接本机工作台」。团队工作台仍可通过对应入口登录。

1. 找货源时，打开 Amazon 商品详情页，点击插件“复制商品图并打开 1688”。插件复制主图后打开1688。
2. 在1688页面直接点击搜索框，按 Ctrl+V 粘贴图片；不要点击“以图搜款”或相机/上传按钮，不要打开上传弹窗。
3. 完成页面验证后再人工筛选候选。

v0.7.13：采集1688图片时检查已观察到的 CDN 缩略图对应原文件，实际加载且尺寸更大才替换；失败时保留原缩略图。工作台保留原链接、尺寸和来源区域，不能把加载成功当作图片审核通过。已安装插件需重新加载后生效；源码更新不会修改正在使用的旧插件。

若已在1688页面，点插件“复制参考图；到搜索框粘贴”，再在搜索框按 Ctrl+V。


v0.7.12：1688货源采集支持V-DETAIL-Z开放组件中的详情图片，保留来源区域和原始尺寸，不自动标为已审核。只读取供应商详情区域，不采集插件工具箱图片。更新已安装插件需在ego扩展管理页重新加载；运行中的旧EXE所附插件包未随源码自动更新。

v0.7.14：按商品详情区域识别动态命名的详情组件（已观察到 Z、2、U、W 等后缀），采集其公开详情图片（含图片形式尺码表），排除链接到其他1688商品的推荐图。尺码表仍需人工核对转录，不将图片加载或采集当作审核通过。已安装插件须重新加载后生效。
