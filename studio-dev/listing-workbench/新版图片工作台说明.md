# 新版图片工作台

2026-10-26：将 IvyeaOps 的 VisualStep React 编辑组件改编接入本软件，保留钧飞品牌、团队登录、产品资料、真实素材库与现有服务商密钥。

使用：产品库 → 编辑产品 → 图片工作台 → 素材库设主体图（最多再选3张细节）→ 选择商品套图5–8张或A+模块4–6张 → 填创意需求 → 策划 → 点击分镜检查、编辑文案与高级提示词 → 单张生成或整套生成 → AI质检 → 人工核对 → 复核整套 → ZIP下载。只补缺失图片可保留已生成图片。修改文案会保留历史并让修改卡片待重画；历史版本可恢复并重新人审。

后台任务及分镜存储在服务器，关闭浏览器仍继续；服务重启后批次暂停，已经提交的单图任务继续查询，不会自动重复提交付费生成。查看未完成任务后再补缺图。整套复核和单图QC是模型判断，不是像素级测量或合规保证。草稿也可下载，带DRAFT标识。

与原项目范围差异：迁入实际分镜编辑组件及其交互，后端适配本软件的APIMart生成、DeepSeek视觉策划/质检与任务数据库；未迁移原项目全部后端、PSD导出或其私有配置。实际调用仍取决于服务商余额、模型权限和所选DeepSeek模型是否支持图片输入；不支持时明确报错，不以文字猜测冒充读图。

验证：构建和类型检查通过；Python回归测试通过；隔离产品完成HTTP整套7张模拟生成、归位、质检状态及同源图片下载；实际页面验证分镜切换及修改保存。测试使用模拟模型，没有消耗真实生成额度；最终图片质量需使用真实产品试图确认。
