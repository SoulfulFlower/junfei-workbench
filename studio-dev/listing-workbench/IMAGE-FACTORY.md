# 云端和本地图片工厂

图片工作台沿用现有 AI 分镜、素材库、套图图位和版本。确认完整分镜后，从卡片或整套入口生成。产品来源、套图视图、历史版本、人工核对和原有导出入口共用一套记录。

## 切换服务

- **云端**在「模型设置」选择 OpenAI 兼容、APIMart 或 AIGoCode。云端请求继续使用已有报价、订阅额度和提交日志。现有云端双参考能力用于变体整套换色。
- **本地**在本机启动 ComfyUI，监听 `127.0.0.1`，将兼容的 SD 图生图 `safetensors` Checkpoint 放入 ComfyUI 的 `models/checkpoints`。进入「模型设置 → 本地生图 · ComfyUI」，检查设备和模型，填写文件名及重绘强度，再保存并切换。设置只允许本机工作台管理员操作。支持 `http://127.0.0.1:8188` 等回环端口。[ComfyUI 本地 API](https://docs.comfy.org/development/comfyui-server/comms_routes)

本地预设使用一张主体参考图，采样画布最长边为 768 px，输出按所选尺寸插值放大。输出尺寸和采样尺寸均保存在任务中。双参考换色请切回云端。ComfyUI、模型和显卡运行库独立配置。工作台不会因本地服务不可用或任务结果未知而切换到付费接口。已提交任务始终按原生图服务和外部任务号查询。

## 质检和套图版本

- 生成结果缓存后记录文件 SHA-256、格式、尺寸和技术检查。完整套图复核会检查重复文件并保存逐图哈希。发生图位更新后，应按新版本复核。
- 云端模式保留已有视觉模型检查及人工确认。纯本地成图自动做技术检查，商品外观、颜色、附件、图中文字和清晰度由操作员逐张核对。本地套图在人工核对前显示待审。分镜策划仍走工作台当前配置的视觉模型。
- 套图及历史图位版本保存原任务回执和质检结果。未确认的提交应按原任务查询。主图、服装尺码图和 ERP 导出的现有证据门槛继续适用。
