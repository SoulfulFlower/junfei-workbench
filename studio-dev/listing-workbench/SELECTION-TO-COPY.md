# 原选品任务接续到文案（2026-11-06）

这是从选品记录接到已有研究与文案模块的增量功能，不是自动发现商品、自动核实网页事实或完整无人值守刊登。字段和证据通过本地规则检查，也不等于对外部事实作真实性保证。

## 使用

1. 在选品页把候选加入智能体核验任务。默认仍不启用付费研究或文案。
2. 补齐当前产品的选品证据、匹配货源、规格与变体等资料。
3. 打开原任务详情，选择“接续竞品研究与文案”。仅原选品入队、已停止的生产任务和草稿店铺档案可用。
4. 填写本任务人民币预算，可选填写最多5个已核验竞品ASIN，并明确同意调用研究/文本服务及费用说明。
5. 保存时重新检查当前资料和选品规则。通过后仅将原任务排队，点击“开始”才执行。没有可用竞品或配置时停止，不伪造数据。
6. 生成的草稿保留原文案，需要查看、采用和审核。已有合格文案也在文案阶段停止，不自动作图、导出或操作ERP。

## 费用与范围

预算只是记录，不是实时账单硬上限。实际费用须核对所配置服务商；本功能不承诺在该金额内完成。配置动作不调用研究或模型，也不自动启动。

本次固定范围为选品/资料检查、研究和文案。图片、导出、上传、ERP保存、发布和在售核对均不在此范围内。进度条只显示本次四个阶段；停止使用“待补齐”状态并明确原因，不标成整条流程完成。

原任务ID、店铺档案和证据链不变。重检不能删除或更换原候选身份；每次研究/文案派发前再次核对当前工作台资料和非跳过的选品检查。旧快照和检查结果归档，尝试记录不会清空。重复提交同一配置只返回现有状态，不启动、不重做。已有研究/文案调用、未知尝试或交付/ERP历史的任务不能借此重新配置。资料版本发生变化时需刷新后重试。

## 验证与部署边界

后端测试使用临时SQLite、合成且来源明确标注为夹具的产品和证据，真实执行选品/资料规则；模型及研究服务完全模拟，外部网络阻断。覆盖28项接续场景，包括两段研究到文案、草稿采用后重检、超时不重试、空历史记录、未知范围、非法阶段与越界防护。

另有9项离线界面逻辑测试覆盖费用确认、预算、取消、重复点击及导航离开。未进行真实账户的可视浏览器验收。

真实新商品选品到模型生成未运行，未上传、未保存或发布ERP。生产服务没有部署；便携包须以其版本和随包验收范围为准。另一台实体电脑的首次启动仍未验收。
