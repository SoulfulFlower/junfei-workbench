# Listing 工作台前端优化计划

以产品库中的「Listing 工作台」为统一入口。当前截图中，同级页面分别出现「Listing 文案」和旧「Listing 编辑」，文案工具栏同时突出生成和提交审核，核心编辑区还被多层折叠和素材挤占。改版统一页面层级和操作优先级。

## 页面结构

- 关键词与评论分析、Listing 文案、视觉套图、交付共用工作台骨架。统一面包屑、返回产品库链接、产品摘要、步骤导航、页标题和正文左边线。页面仅有一个主标题。步骤使用有当前状态的导航。
- 产品库和任务台打开产品时走同一入口。保留当前产品和步骤以便刷新恢复，加载后从当前账号已授权的产品列表验证产品。产品不可用时返回产品库。
- 文案页在操作区后直接显示待采用草稿、必要状态和编辑字段。五个字段用标题、留白与分隔线分组，页内链接用于快速定位。提示词、写作工具和低频说明集中在一层可展开区域。素材、变体和货源操作放在产品资料步骤。
- 视觉套图使用统一页头，现有母版、换色、历史成图和导出候选仍可访问。交付保留站点文案导出、整套 ZIP 和审核入口。

## 操作优先级

| 页面或状态 | 主操作 | 其他操作 |
| --- | --- | --- |
| 关键词与评论分析 | 获取并分析关键词与评论 | 编辑资料、查看变体、更新货源、切换步骤 |
| 文案未完成 | 生成站点文案 | 版本记录和写作辅助 |
| 有待核对草稿 | 对比并选择采用 | 暂不采用、继续编辑 |
| 标题、五点及产品描述齐全 | 保存并提交审核 | 重新生成、版本记录 |
| 视觉套图 | 当前编辑区的出图操作 | 参考素材、图片技能、历史成图和换色 |
| 交付 | 下载整套 ZIP | 导出当前站点文案、前往审核中心 |

主操作按任务状态决定。生成中显示进度，字段错误及保存冲突留在对应流程内。复用已有处理函数，保留自动保存、字段验证、草稿采用、生成和审核业务语义。

## 验收

1. 用产品库入口、任务台入口和刷新打开同一产品，核对标题、产品、当前步骤及布局。
2. 检查文案空白、生成中、待采用、字段齐全和已有审核状态，确认主操作明确，文案字段直接可见。
3. 检查四步骤键盘导航、窄屏换行、文案页内定位，以及版本、货源、变体、历史图片和交付入口。
4. 用前端检查和项目现有流程测试验证。验收仅使用只读数据或测试样本，模型生成和提交操作由模拟处理。

参考 [GOV.UK 按钮](https://design-system.service.gov.uk/components/button/)、[标题](https://design-system.service.gov.uk/styles/headings/)、[分隔线](https://design-system.service.gov.uk/styles/section-break/)及[按需展开内容](https://design-system.service.gov.uk/components/details/)。

## 本次验收记录

- 用独立测试样本在 EGO 浏览器核对了产品库入口、直接链接、刷新恢复、四步骤页头对齐、字段定位，以及 390 像素宽度下的单列文案编辑。
- 用同一套前端脚本和模拟接口核对了生成中、空白、待采用与可提交状态，验证素材与文案分区、套图与换色切换、交付入口及无权访问产品时的回退。任务台采用草稿使用同一工作台入口。
- 验收数据来自本地测试样本，测试没有提交生产请求。
