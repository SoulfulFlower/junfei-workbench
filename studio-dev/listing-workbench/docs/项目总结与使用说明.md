## 快速使用：每天从这里开始

1. 双击桌面“亚马逊智能体工作台”，打开 http://127.0.0.1:18765 ，登录自己的账号。
2. 打开ego专属工作区，确认卖家精灵、1688和钧飞登录正常。
3. 向我说明数量、店铺、站点和“草稿／发布”；已有任务提供产品ID或任务ID，让我先核查原记录再继续。
4. 在任务台查看阶段和缺项；遇到登录或验证码，在同一工作区完成后回复“完成，继续”。
5. 交付时查看ERP实际状态，领取以父SKU命名的文件夹及ZIP。默认存放在 `D:/桌面/潘总写的产品`。

可直接复制的任务指令：

> 按固定流程做1款新品，示例店铺-美国、US站，使用ego；货源按销量选，生图每款5元、每日200元。完成文案、七图、导出并保存草稿；分类和模板由你判断，缺资料先记录，继续其他可执行环节。

若需要正式刊登，把“保存草稿”改为“正式发布，ERP显示发布中即交付”，并提供已确定售价或要求按配置核算。

## 2. 如何启动

1. 双击桌面“亚马逊智能体工作台”快捷方式。
2. 浏览器打开本机工作台；若没有自动显示，可手动访问 http://127.0.0.1:18765 。先启动EXE，再访问网址。
3. 登录自己的工作台账号。产品、任务和模型设置按账号隔离，找不到产品时先确认账号。
4. 需要我操作网站时，使用ego（lite）专属工作区。EXE自动打开的页面可能在系统默认浏览器中，需在ego里访问同一工作台网址；网站登录状态不会自动跨浏览器共享。

这是本机地址，只在运行服务的这台电脑上使用，不是公网网站。内置教程若出现云端地址或旧Edge操作，当前本机流程以本文和项目最新配置为准。

## 3. 第一次使用要检查什么

1. 在“模型设置”检查当前账号的文案及图片服务配置，使用对应测试入口。不要把密钥贴到聊天、产品文案或报告中。
2. 在“任务台／智能体任务中心”的“店铺与站点”保存本账号的店铺档案，核对准确店铺名、站点、库存、处理时间和运费模板。
3. 在ego专属工作区登录需要的网站：工作台、卖家精灵、1688、钧飞ERP。出现验证码，由你完成后告诉我“验证完成，继续”。
4. 在“产品库”确认目标产品ID和实际资料；新产品先建记录，再开始生产。多个员工不能共用别人的产品记录。

多店铺分别建档。切换店铺时明确店铺和站点，不能把默认美国店铺或本款发布授权套到所有店铺。

定价按配置中的采购成本、适用运费、其他费用、汇率6.8、平台费15%和总成本加价50%计算，结果向上取整到美分；50%加价不是50%销售利润率。旧物流报价、未确认附加费或缺包装数据时，软件给出的只能是草稿估价。正式发布采用已核实依据或用户明确指定的本款售价；旧编织包的$38.47不能套到新品。

## 5. 日常怎么用

### 最方便：直接给我任务

从选品开始，可以这样说：

> 按固定流程做1款Amazon US产品，店铺示例店铺-美国。用ego专属工作区，货源按销量选，生图按每款5元每日200元，先保存草稿。

已有商品，可以这样说：

> 处理我当前账号里的产品【产品ID】，货源【1688链接】。继续研究关键词、写Listing、做七图、导出并保存钧飞草稿。

明确发布，可以这样说：

> 发布产品【产品ID】，店铺【准确店铺名】、站点【US】、售价【美元金额】。ERP显示发布中即交付，文件按ERP父SKU归档到潘总写的产品。

断点继续，可以这样说：

> 继续原任务【任务ID／产品ID】，先核查已有生图任务和ERP回执，不重复生成、不重复提交。

收到资料后，我按已有授权连续执行，只在登录、验证码、必要经营数据或实际异常处需要你协助。分类和适配模板由智能体根据产品及目标页面判断，不要求你每款手动选择。

### 自己在工作台查看或操作

1. 打开“产品库”，选择自己的产品，核对材质、款式、颜色尺寸、采购价和素材来源。用“ASIN／货源导入”时，货源负责本品事实，竞品负责研究。
2. 打开“任务台／智能体任务中心”，选择店铺档案、产品和数量，填写任务目标。
3. 选择执行范围：“准备检查”用于查缺项；“生产流程”按已接入工具推进。AI规划和自动工具选项只控制相应能力，不代表整条链已无人值守接通。
4. 创建并开始任务，查看阶段结果和工具接入状态。准备检查结束只代表检查做完，仍需看具体生产、导出和ERP结果。
5. 在“Listing 编辑”核对标题、五点、描述和后台词；在图片／视觉工作台检查真实产品还原、七图顺序及变体对应关系。
6. 缺资料补齐后使用“更新资料重检”；导出后保留交付包和审计报告。有ERP绑定或提交记录时先对账，不另建任务绕过。

固定阶段：任务规划 → 选品与货源 → 竞品关键词 → Listing文案 → 商品图片 → 交付导出 → 钧飞本地预检 → 钧飞刊登 → 在售核对。

## 6. 浏览器和以图找货

浏览器默认用ego（lite），脚本入口为项目 `automation/ego_browser.py`，复用配置中的专属TaskSpace。不默认启动Edge，也不复制Cookie迁移登录。

1688以图搜索的固定操作：复制商品图片 → 聚焦1688搜索框 → 粘贴图片 → 查看新结果标签。不要点击“以图搜款”、相机或上传按钮，避免弹出上传框。

若工作区丢失，重新建专属工作区并登录；先核对原任务和已有结果，再继续。不要因为窗口没显示就重新生图或重新发布。

## 7. 状态和异常怎么看

| 状态／现象 | 含义与处理 |
| --- | --- |
| 待开始／执行中 | 排队或正在执行，先看当前阶段 |
| 待补齐／需核对 | 查看具体缺项，补资料或核查结果后续跑 |
| 检查完成 | 准备检查结束，不等于图做完或刊登完成 |
| 生图running／结果未知 | 先按原外部任务号查询，不重新付费提交 |
| ERP保存成功 | 仅对应产品库或草稿保存，查看实际保存位置 |
| ERP发布中 | 本项目按你的标准可交付；不代表Amazon已可购买 |
| Amazon在售 | 需要另行核对ASIN、子SKU和前台状态 |
| 登录页／验证码 | 在同一ego工作区完成登录或验证，再继续 |
| 本机网址打不开 | 先运行桌面快捷方式；仍失败则反馈启动错误，不删除数据或重装覆盖 |
| ERP错误或超时 | 保存错误和任务号，核查远端结果；修正后继续原记录，避免重复刊登 |
