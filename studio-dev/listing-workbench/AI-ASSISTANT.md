# 对话工作台

参考用户提供的IvyeaOps README及ADR-0015、0021、0027、0032、0035，独立实现“当前产品上下文 + 对话 + 回答下的动作与产物”，没有复制其程序或执行其脚本。并非导入完整IvyeaAgent，暂不支持任意工具、终端操作、知识库检索和运行期间插话。

右下角“AI助手 · 对话办事”在登录后常驻。进入编辑产品后自动关联当前产品已保存事实、当前站点Listing和最新套图分镜。通用页面是无产品的普通问答。每位员工只可读取和执行自己的会话，历史保存在服务器，产品资料仍是团队共享。

可问问题、上传附图、读当前主体图、讨论套图、修改分镜、提出单张出图请求或预览Listing草稿。动作卡片放在回答下，点击执行才调用策划或生成/保存。图片生成仍走共享视觉工作台、后台AI质检与人工确认，默认不自动返工。文案草稿不会自动覆盖产品Listing，可复制或继续讨论。

附图仅发送当前第一张作为主体视觉输入；至多4张参考图可作为后续策划与作图输入。每条消息提示会发给DeepSeek并产生模型费用；图片动作说明额外APIMart与质检费用。不向模型暴露API密钥。模型提出未知工具会拒绝，执行过的卡片不能重复点执行，24小时后旧动作需重新讨论。

图片页优先展示“与AI讨论这个产品的图片”，分镜及高级设置折叠，主体图仍在真实素材库选择。打开对话侧栏不压缩原页面，收起继续核对表单即可。

当前为整条回复完成后显示，不是逐字流式输出；对话请求运行时会显示状态，不伪造模型思考过程。自动重试关闭，异常结果保留在会话里。55项自动测试通过，包含账号隔离、上下文、动作确认、防重复、版本保存与生成参数；页面以模拟模型验证聊天和历史记录。没有因此自动运行真实商品付费生成。
