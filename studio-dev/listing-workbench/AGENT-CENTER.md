2. 选择现有产品和执行范围，填写目标。准备检查不创建交付包；生产流程会在检查通过后导出，再运行钧飞的本地格式与图片预检并生成计划包。此步不会登录或提交ERP。
  目标款数支持1–30，选择现有单款时为1；启用AI规划或自动文案时必须填写人民币预算。预算用于明确单任务费用意图，但服务商价格及多轮调用成本尚未接入，因此仍不能视为硬性封顶。
3. 点击创建，再点击开始。已接入工具依序检查事实、竞品关键词、文案和图片，记录逐步结果。一次检查尽量汇总全部缺项。
4. 查看执行记录；缺项旁的“弹窗查看怎么补”会给出具体补充要求，产品事实缺项可直接打开产品资料编辑页。修正资料后点击“更新资料重检”，归档旧快照和结果，再从事实检查继续；保留原规划，避免重复文本模型调用。仅检查已结束或明确阻塞、且无交付/刊登记录的任务允许更新；异常任务仍须先对账。暂停在当前工具结束后生效，继续不会重跑已完成工具。程序中断的任务标记需核对，不自动重发。

## 数据边界

市场调研导入候选现在在资料阶段附带选品证据检查：近7天卖家上架日期、中国FBM、实际前台搜索、其他ASIN同款、SellerSprite同款排名、IP检查及台账核对记录。缺证据阻断生产任务后续付费研究与文案。此检查只校验证据字段，不自动采集、不证明来源真实、不写正式入选表。用户指定的既有产品保留原路径，不冒充自动选品通过。沿用旧任务阶段及游标，避免升级后重跑付费操作。

候选任务明细提供“下载选品证据填写模板”，按候选ASIN和店铺站点生成JSON字段骨架，并附来源填写、近7天上架口径、SellerSprite排名和权利检查说明。模板中的来源、判断和状态均为空/未检查，直接提交仍会被准入检查阻断；它只统一收集格式，不采集或认证证据。

采集插件 v0.7.8 可在 Amazon `?me=SellerID` 店铺搜索结果页读取最多50条可见商品卡片并生成本账号选品观察报告；在“选品调研”历史中可选择候选、入库并启动免费证据核验。只记录当前页可见商品和显示排序参数，不后台翻页；排序不能证明近7天上架，店铺页本身不证明中国卖家、FBM或同款销售排名，缺证据仍阻断。

若任务已有本账号浏览器观察，另提供“下载已整理观察草稿”：只预填Amazon商品页/前台搜索的来源链接、采集日期和可见原文，并附SellerSprite可见行供复核。卖家国家、FBM、近7天卖家上架日期、同款ASIN/数值排名、IP权利及排重配额均保持未判定；观察仍与`selectionEvidence`分离，下载后直接作为准入证据仍会被阻断。

证据草稿现会从SellerSprite可见行中提取明确标注`Sales rank`、`BSR`或中文“排名”的单一数值，以及明确标注`Listing date`、`Listed on`、`上架日期`等标签的ISO日期，分别作为`rankSuggestions`和`productListedDateSuggestions`显示，并保留该行原文、来源URL和ASIN。普通数字、价格/评论数字、多个排名值、非ISO日期、Amazon `Date First Available`或占位符不会生成建议。建议不自动选择同款、不写入`matchedRank`或`sellerListedDate`；准入核验仍要求人工确认排名口径、卖家上架日期和同款关系。自动解析仅用于减少抄录，不会通过选品门槛。

选品观察草稿会把同一候选 Amazon 前台搜索结果与 SellerSprite 可见行按 ASIN 交叉关联；两边都出现且 SellerSprite 原文含唯一明确排名值的候选排到“选品候选交叉复核队列”前部。排序只看证据是否跨来源出现，不按排名数值大小，不自动认定 exact/strong 同款、销量或准入，不写入正式选品证据。页面显示对应Amazon标题与SellerSprite原文，帮助用户集中复核高价值候选。

选品报告新增“智能体自动挑选前10个并启动核验”：基于历史月销量与评论数的固定公式优先安排免费证据核验；历史指标齐全时再轻微优先本次价格区间内候选，指标缺失时保留来源顺序。ASIN深度调研最多1个，数量不超过报告设置。每条候选会返回可见排序理由，状态明确为`review_queue_only`。此排序不等于产品机会结论、近期上架、利润或选品准入；队列仍运行原证据闸门，未通过不进入付费研究/文案或刊登。

API在既有登录、同源写入、账号变更检测及账号独立runtime之后处理。profiles/tasks均按服务端认证的user_id查询，不接受客户端指定owner。配置、任务和事件保存在当前账号DATA/agent-center.sqlite3；交付包在DATA/agent-results/<任务ID>/delivery.zip。接口不公开工作台快照、凭据或本地目录。

automation/config.json和CLI台账仍用于Codex手工全流程调度。网页中心使用账号隔离的店铺档案及工具执行台账；**两者目前不自动同步**。不把“准备检查完成”写成CLI中的生产阶段通过。现有CLI配置窗口也不会改动网页档案。

本地源代码和 `dist/AmazonAgent/` 桌面发行目录已重建，冒烟验证只使用临时数据；未部署云端，未重启现有生产服务，未操作真实ERP。隔离预览：从项目根目录运行 `py -3 automation/preview_agent_center.py`，使用脚本内的测试账号；数据位于临时目录，与真实账号及产品分离，不配置模型凭据。

## 可选自动竞品研究（2026-11-01）

选品报告现可选择本账号同站点店铺后“加入产品库并启动智能体核验”。逐款保存来源报告ID、ASIN和任务ID；重试沿用所有状态的既有任务，只有新任务自动启动。此入口关闭所有付费工具，缺少选品证据立即阻断。产品入库先提交，任务逐款提交；部分失败返回每款原因，可重试补建缺失任务，不恢复删除产品。详见SELECTION.md。

生产任务可勾选自动研究并指定1–5个竞品ASIN（或沿用产品已有竞品输入），先通过事实检查，再调用当前账号可用的卖家精灵正文/反查词及文本分析。已有可用研究不重查；不自动采评论或额外挖词。额度与文本费用待账单核实，预算尚非硬封顶。来源数据不等于同款已验证。
