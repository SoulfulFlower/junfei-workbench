# 项目维护约定

用户最新指令优先。按 `listing-workbench/MODULES.md` 定位模块和检查入口。

- 不将账号、密码、密钥、浏览器会话、数据库、产品资料或真实执行回执提交到仓库。
- 使用隔离测试数据；未知模型或 ERP 请求先核对原回执，避免重复提交。
- 图片、变体和来源事实必须可核验，不虚构商品属性或人工审核记录。
- TSX / TS 修改后运行前端构建；后端修改按模块运行相关测试。
- 新环境从 `automation/config.example.json` 建立本地配置；公开示例不提供任何真实账号或店铺授权。
- 保留原版权、开源许可和对应源码说明。
